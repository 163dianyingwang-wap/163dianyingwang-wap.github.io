— SECTION 05 / 观影问答 —

关于这个手账，常见的问题

如果还有没问到的，留言区见。

Q
「163电影网」这个名字，和电影有什么关系？
+
它是一个手账编号，不是品牌背书。我们的意思是：每一部被记下来的片子，都值得被编号、被标注、被反复翻看——就像你手边那本写满字的小本子。
Q
清单上的"已看""想看"可以自己改吗？
+
目前是编辑部统一维护的版本，存成浏览器书签即可随时回来翻。后续版本会开放个人勾选与本地保存，不收集任何观影数据。
Q
你们怎么挑片，会不会只挑热门的？
+
不追首发，不抢热度。每周固定留两个名额给没有话题、没有卡司、但确实值得被看到的片子，这部分是我们最看重的内容。
Q
评分和榜单是怎么来的？
+
编辑部内部投票，每人一票，互不提前通气。榜单只给共识度，不公布个人分数，也不接受任何形式的推广投放。
Q
能不能帮我列一张给朋友看的片单？
+
可以。在留言里写清对方偏好和观影场景（一个人 / 约会 / 家庭 / 朋友聚会），我们会回一封带编号的片单邮件。
